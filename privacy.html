Last updated: November 21, 2026

yt-auto is a personal automation tool operated by its owner to publish the owner's own videos to the owner's own YouTube channel. It is not offered to or used by any other person.

Google user data we access

The app requests one permission from the owner's Google account: the ability to upload videos to the owner's YouTube channel (the youtube.upload scope). It does not read, download or analyze any other YouTube or Google account data.

How the data is used

Access is used only to upload videos that the tool itself created to the owner's channel and to set the video title, description and tags. The tool does not collect personal data from viewers, subscribers or any other individuals.

Storage and security

The authorization token is stored only as an encrypted secret in the owner's private code repository and is used only to run the owner's scheduled uploads. No Google user data is stored in any other database or system.

Sharing

We do not sell, share, transfer or disclose Google user data to any third party.

Google API Services User Data Policy

yt-auto's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke the app's access at any time at myaccount.google.com/permissions. Revoking access stops all uploads.
